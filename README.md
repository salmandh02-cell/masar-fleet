# نظام أسطول الشركة – التطبيق المستقل

تطبيق ويب يعمل من الجوال والحاسوب. يمكن تثبيته على الشاشة الرئيسية كتطبيق.

| الجزء | يعمل على |
|---|---|
| الواجهة | GitHub Pages (مجاني) |
| تسجيل الدخول | Firebase Authentication، بالإيميل وكلمة المرور مع تأكيد البريد |
| البيانات والصور | Cloud Firestore |
| الصلاحيات | `firestore.rules`، وتطبَّق على الخادم فلا يمكن تجاوزها من المتصفح |

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | النظام كاملاً |
| `fb.js` | الربط مع Firebase: الدخول، البيانات، الصور، التنزيل، سجل التدقيق |
| `sw.js` | يعرض الصور والمرفقات المحفوظة، ويحتفظ بنسخة منها على الجهاز |
| `config.js` | إعدادات مشروع Firebase وإيميل مالك النظام |
| `firestore.rules` | قواعد الأمان، وتُلصق في Firebase Console |
| `tools/build_from_artifact.py` | يبني `index.html` من نسخة النظام داخل Claude |

## أنواع المستخدمين

| النوع | الصلاحيات |
|---|---|
| مدير النظام | كل الصلاحيات، ومنها الحذف والإعدادات والمستخدمون وسجل التدقيق |
| مدير الحركة | الإضافة والتعديل في البيانات التشغيلية، بدون حذف أو إعدادات |
| سائق | يرى صفحة الفحص الأسبوعي فقط، ويسجل الفحص بالصور ويحدّث العداد |
| مطلع | عرض فقط |

إضافة مستخدم: من «الإعدادات ← المستخدمون والصلاحيات» تكتب اسمه وإيميله ونوعه. بعدها يفتح الرابط وينشئ حسابه بنفس الإيميل، ويؤكد بريده من الرسالة التي تصله.

## التحديثات

يُعدَّل الكود في هذا المستودع وتُرفع التعديلات (push)، فيحدّث GitHub Pages الموقع خلال دقيقة تقريباً. البيانات لا تتأثر بالتحديث.

## السعة

الخطة المجانية (Spark) تعطي 1 جيجابايت للبيانات والصور، وحوالي 50 ألف قراءة يومياً.

تُضغط كل صورة إلى حوالي 100 إلى 200 كيلوبايت. مع 100 سيارة وفحص أسبوعي بأربع صور، تقترب المساحة من الحد خلال 4 إلى 6 أشهر.

عندها تُرقّى الخطة إلى Blaze (ادفع حسب الاستخدام). تكلفة المساحة الإضافية حوالي 0.18 دولار لكل جيجابايت شهرياً.
